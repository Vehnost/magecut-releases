# Magecut Local for Codex — Windows x64

Полный локальный видеоредактор: таймлайн, импорт, текст, анимация, просмотр кадров и экспорт MP4. Работает через MCP и браузер без Electron.

## Установка через каталог

1. Codex → Настройки → Плагины → Добавить → Добавить маркетплейс.
2. Источник: `Vehnost/magecut-releases`. Git ref: `main`. Выборочные пути оставить пустыми.
3. Установить **Magecut Local** и открыть новую задачу.
4. Написать: **«Открой Magecut, дождись установки редактора и открой editorUrl из magecut_status во встроенном браузере».**

Каталог плагина занимает около 54 КиБ. При первом запуске автоматически загружается комплект редактора вместе с Node.js (~623 МиБ), проверяется SHA-256 и распаковывается в `%LOCALAPPDATA%\MagecutLocal\marketplace`. Во время установки MCP уже отвечает и показывает этап загрузки. При обрыве загрузчик повторяет запрос и продолжает с сохранённого байта. Частичная загрузка сохраняется между задачами. После 30 неудачных попыток откройте новую задачу для продолжения. Повторные запуски установленного редактора используют сохранённую копию. Оставьте около 2 ГиБ свободного места для загрузки и распаковки.

Редактор открывается локально на `127.0.0.1:14340`; вкладку нужно держать открытой во время монтажа. Одна активная сессия редактора одновременно. Если ранее был установлен отдельный MCP `magecut_local` или старый плагин, отключите его, чтобы не управлять одним проектом из двух редакторов.

Проекты сохраняются в `~/.magecut-local/projects`. Удаление плагина не удаляет проекты или кэш редактора. Для удаления кэша сначала закройте все сессии Magecut.

## Что входит

Редактор, Node.js, MCP (28 инструментов), FFmpeg, шрифты и переходы. Python, дополнительные AI-модели и платные облачные службы не включены. Для первой установки нужен интернет; обычный монтаж и экспорт работают локально. Облачные функции могут требовать отдельные ключи и отправлять данные выбранному сервису.

Архив также доступен в [Releases](https://github.com/Vehnost/magecut-releases/releases/tag/v0.2.0) для отдельной установки через `Install.cmd`. При установке плагина запускать `Install.cmd` не требуется.

JavaScript редактора поставляется минифицированным, без source maps. Загрузчик PowerShell открыт для проверки. Это не шифрование и не защита от извлечения кода. Лицензии включены в комплект.
